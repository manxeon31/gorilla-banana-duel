# Gorilla Banana Duel

A two-player browser game with projectile physics.

- **60s Death Match:** unlimited bananas; highest score wins.
- **5-Banana Match:** five alternating throws per player.
- Body hit: 1 point
- Headshot: 2 points

## Run locally

```bash
npm install
npm run dev
```

Built with React, TypeScript, Vite, and Canvas.
